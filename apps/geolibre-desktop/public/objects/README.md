# 번들 3D 객체

여기에 둔 파일은 앱과 함께 배포되고, **3D 객체 → 예시 파일** 메뉴에 나타납니다.
클릭하면 `manifest.json`에 적힌 위치·크기·회전 그대로 지도에 올라갑니다.

## 넣는 방법

1. 객체 파일을 이 폴더에 복사합니다 — `.sog` `.splat` `.ply` `.spz` `.ksplat` `.glb` `.gltf`
2. `manifest.json`의 `objects` 배열에 항목을 추가합니다

```json
{
  "objects": [
    {
      "file": "gogiri-park.sog",
      "name": "고기리공원",
      "longitude": 127.0705,
      "latitude": 37.357164,
      "altitude": 2,
      "scale": 0.075,
      "rotation": [-90, 294, 0]
    }
  ]
}
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `file` | 예 | 이 폴더 안의 파일 이름 |
| `name` | 아니오 | 메뉴에 보일 이름. 없으면 파일 이름 |
| `longitude` / `latitude` | 예 | WGS84 십진도 |
| `altitude` | 아니오 | 지면으로부터의 높이(m). 기본 0 |
| `scale` | 아니오 | 배율. 기본 1 |
| `rotation` | 예 | `[X, Y, Z]` 각도 |

`rotation`을 빼면 그 항목은 **통째로 무시됩니다.** 기본값을 대신 넣지 않는 이유는,
스플랫과 glTF의 기준 축이 달라서 잘못된 기본값이 물체를 옆으로 눕히기 때문입니다 —
조용히 이상하게 뜨는 것보다 안 뜨는 편이 낫습니다.

## 좌표를 구하는 가장 쉬운 방법

숫자를 손으로 맞추지 마세요.

1. 앱에서 **3D 객체 → 파일로 올리기**로 그 파일을 엽니다
2. 패널에서 경도·위도·고도·크기·회전을 눈으로 맞춥니다
3. **예시 파일로 저장**을 누릅니다
4. 브라우저 개발자도구 → Application → Local Storage → `geoim3d.object-presets`에서
   그 항목의 `transform` 값을 그대로 복사해 위 형식에 옮깁니다

## 주의: 용량

이 폴더의 파일은 **설치 파일과 웹 번들에 그대로 들어갑니다.** 가우시안 스플랫은
수백 MB가 예사이므로, 여기 넣는 것은 정말 함께 배포해야 하는 것만으로 한정하세요.
`.sog`가 `.ply`보다 10~20배 작습니다.

원격에 두고 URL로 부르는 편이 나은 경우가 많습니다 — 그때는 `manifest.json` 대신
앱에서 URL로 올린 뒤 예시로 저장하면 됩니다.
